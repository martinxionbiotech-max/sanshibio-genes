## 分子机制深挖：SNP 为何能唯一识别个体

SNP（单核苷酸多态性，Single Nucleotide Polymorphism）指基因组中单个碱基位点上的变异。理论上，每个 SNP 位点有 2–3 种等位形式，58 个 SNP 位点的组合数量极其庞大，任意两羽鸽完全相同组合的概率极低，从而形成独一无二的「基因指纹」。这正是[赛鸽遗传学基础](pigeon-genetics-basics.md)中基因型多态性的直接应用。

与「赛鸽飞行能力基因检测」关注「这羽鸽飞得好不好」不同，基因身份证关注「这羽鸽是谁」。前者解读功能基因型，后者锁定个体身份，两者可共用同一份 DNA 样本。

## 基因身份证的核心价值

### 1. 身份唯一性
每羽赛鸽的 58 个 SNP 位点组合几乎独一无二，形成「基因指纹」，杜绝同名混淆。

### 2. 防作弊、防顶替
在赛鸽比赛中，基因身份证可有效防止「AB 鸽」（同名顶替鸽）作弊，保障赛事公平。

### 3. 血统管理
为种鸽建立基因档案，配合[亲子鉴定](https://sanshibio.com/paternity/)实现血统的精准追溯与管理。

### 4. 交易凭证
引种交易时，基因身份证可作为鸽只身份与血统的可信凭证，降低交易风险。

## 常见问题

### 基因身份证和血统书有什么区别？
血统书记录的是谱系与赛绩，可被篡改或造假；基因身份证是 DNA 层面的身份档案，不可伪造、不可顶替。两者结合才能实现血统的「可追溯 + 可信」。

### 基因身份证和足环有什么区别？
足环是「佩戴身份」，可被更换或造假；基因身份证是「基因身份」，基于 DNA 不可伪造、不可顶替。两者结合才能实现真正的身份安全。

### 基因身份证和亲子鉴定有什么区别？
基因身份证回答「这羽鸽是谁」，亲子鉴定回答「这羽鸽的父母是谁」。两者可配合使用，建立完整的血统管理体系。详见[亲子鉴定](https://sanshibio.com/paternity/)。

### SNP 位点为什么能唯一识别个体？
58 个 SNP 位点的组合数量极其庞大，任意两羽鸽完全相同组合的概率极低，从而形成独一无二的「基因指纹」。原理详见[赛鸽遗传学基础](pigeon-genetics-basics.md)。

### 基因身份证多久有效？
一旦建立长期有效，无需更新。鸽子的基因型终身不变，基因身份证可终身使用。

### 幼鸽能做基因身份证吗？
可以。羽毛即可提取 DNA，幼鸽阶段即可建档，方便从源头进行血统管理。

### 基因身份证能用于比赛核验吗？
可以。赛前采血或采羽核验，与档案比对即可识别是否「同名顶替」，是 AB 鸽检测的核心应用场景。
